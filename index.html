About

The engineer
behind the system.

I am a QA automation engineer operating at the intersection of test engineering and AI-powered quality systems. My work goes beyond writing tests — I design frameworks that are architecturally sound, scalable under team growth, and maintainable across long product lifecycles.

My technical depth spans the full testing pyramid. Web, mobile, API, and performance — I've built automation coverage across all four, integrating tool chains into coherent workflows that connect directly to CI/CD delivery pipelines.

I've delivered quality engineering across healthcare platforms, education products, and health insurance systems — domains where precision matters and failures carry real-world consequences. That context has shaped a discipline-first approach to everything I build.

Currently, I'm working on AI automation at a meaningful scale — bringing intelligent, adaptive, and self-aware quality systems into real production pipelines. The next phase of test engineering isn't just faster — it's smarter.

My standard: A test framework is a production system. It deserves the same engineering rigour as the application it validates — clean architecture, zero tolerance for flake, and output that development teams can trust without question.

Case Studies

Real domains.
Real stakes.

Three production environments. Each demanded quality ownership, not just test execution.

01 // Healthcare
Healthcare Platform
Problem
Patient-facing web and mobile features required reliable regression coverage. Manual cycles created release bottlenecks and inconsistency in safety-critical flows.
Contribution
Built integrated web and mobile automation with data-driven architecture, parallel execution, and CI/CD pipeline integration. Covered critical patient journey flows end-to-end.
Outcome
Regression cycle time cut significantly. Defect detection moved earlier. Release confidence improved with repeatable, automated quality gates.
~60%
Reduction in regression cycle time
02 // Education
EdTech Platform
Problem
High-volume student-facing app with complex mobile flows, video integrations, and real-time features. Test coverage was fragmented and manual-heavy.
Contribution
Delivered Appium-based mobile automation and RestAssured API coverage. Aligned test deliverables with sprint cadence, integrating nightly runs into the CI pipeline.
Outcome
Automation coverage expanded significantly without proportional manual effort. API defects surfaced pre-deployment. Execution became a reliable part of every sprint.
3×
Coverage increase vs. prior manual approach
03 // Health Insurance
Insurance Systems
Problem
Deep business logic in claims, policy processing, and document flows required both correctness validation and load-behaviour confirmation at scale.
Contribution
Designed end-to-end functional test coverage. Built JMeter load plans for concurrent user validation. Led RCA documentation for intermittent failures in critical claim flows.
Outcome
Critical business logic defects caught pre-production. Load behaviour informed infrastructure scaling. RCA findings reduced mean time to resolution across the team.
